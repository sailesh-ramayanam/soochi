3rd step is "Coming up with logic"

Logic means step-by-step procedure which explains how to calculate the result for the given input.
This step-by-step procedure is also called as algorithm.

One way to come up with an algorithm is by using the test cases we wrote down previosuly.
Take a test case.
Write down the input.
Write down the expected result.
Now write down, how you arrived at the result.
Let us demonstrate through an example.

One test input from above is
6
1
2

3
3
3

I will try to explain what I did.

I looked at the first line. It contains 6. So, I came to know that there will be 6 values in the list.

Then I looked at 1.And counted how many times 1 occured in the list.

Then I looked at 2.And counted how many times 2 occured in the list.

Then I looked at 3.And counted how many times 3 occured in the list.

I reached the end of the list, then I compared count of each number with its value. Numbers whose count is same as its value are lucky number

For this test case I got three lucky numbers, but output will be 1, since the number 1 is having least index

Now imagine that the list size is 1000.
What will you do? Put it in words.

Following are some hints to put the logic in words.

1. As I process 1000 values, it will be difficult for me to remember the frequency of all numbers in my memory. So, I will take a paper and write down the number with its frequency. That way, for every value, I will update the paper and I don't need to worry about forgetting.
2. If it is a small list like 3 or 5 values, then it is easy for me to remember how many values I checked. But 1000 is a large number. So, to avoid checking more than 1000, I will also keep a count of how many values I checked until now. Whenever it reaches 1000, I will stop processing. This count also, I will write on a paper. 
3. Actually I don't have to stop iterating through array, once I got the lucky number. There is no point in counting frquncy of any other number once we got the lucky number

Following is what I came up with.

1. Read list size
2. Write down 2 things - count and array. Initially count will be 0 and array will be empty
3. Take a value and store it in array. Repeat this untill I reach end of the list
4. Now I will take the first element of array
5. Increase the count value
6. Move to next element of array and compare it with the previous element
7. If current element and previous element have same value then increase my count by 1
8. If current element and previous element doesnot have same value then compare count value with the previous eleement value,
	8.1 If they are equal then I will stop there since I got the lucky number and I will dispay the lucky number.
	8.2 If they are not equal then I will again assign value 1 to count (Why 1 why not 0?, since we have move to new element and its count is currently 1)
9. Repeat steps 5 to 7 until we reach end of array or we have got the lucky number.
10. After reaching end of array, I have to cross-check if the frequency of last element is same as its value or not. If equal I will dispaly that number since I got the lucky number
11. If none of the element is lucky number then I will dispay output as -1
