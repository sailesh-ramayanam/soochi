# Description
What is your dream project that you'd like to make after you learn React? Lets write them using React itself.

## Functional requirements
1. create a component `ProjectName` and return an Html element with suffix `Project Name : ${your project name}`.
2. create another component `ProjectDescription` and return an Html element with suffix `Project Description : ${your project description}`.
3. Return both components to `App` component where they should render.

## Other requirements
1. The `ProjectName` component should have an attribute `data-ns-test` with value `project-name`
2. The `ProjectDescription` component should have an attribute `data-ns-test` with value `project-description`
