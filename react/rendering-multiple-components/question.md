# Description
What is your dream project that you'd like to build after you learn `React`? Let us display it, using `React`.
Create a page that displays
1. Project name
2. Project description

# Requirements

## UI requirements

1. A text for project name.
    - `Project Name : <your project name>`
    - E.g. `Project Name: Coffee Cart`
2. A text for project description. 
    - `Project Description : <your project description>`
    - E.g. `Project Description: Coffee cart sells the world's tastiest coffee powders. You can even customise your coffee mix.`

Please refer to `Sample UI` section below, for an example. You can use your own project name and description. 

1. Project name and project description must be rendered by two separate `React` components
2. Project name must be rendered by `ProjectName` component
    - `ProjectName` component should have an attribute `data-ns-test` with value `project-name`
3. Project description must be rendered by `ProjectDescription` component
    - `ProjectDescription` component should have an attribute `data-ns-test` with value `project-description`
