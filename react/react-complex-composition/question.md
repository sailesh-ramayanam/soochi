# Description
The idea of functional programming is to write small and reusable functions and then compose them to form more complex code. Your task is render the `TypesOfFruits` component in `Fruits` component and render `Fruits` component in `App` component

# Requirements

## UI requirements

1. Your display should contain the content from `TypesOfFruits` component. 
    For example : 
    ```
    const TypesOfFruits = () => {
    return (
        <div id="typesOfFruits">
        <h2>Fruits:</h2>
        <ul>
            <li>Apples</li>
            <li>Blueberries</li>
            <li>Strawberries</li>
            <li>Bananas</li>
        </ul>
        </div>
    );
    };
    ```

    output:

    ```
    Types of Food: {/* This is from App Component */}
    Fruits:
        Apples
        Blueberries
        Strawberries
        Bananas

    ```
