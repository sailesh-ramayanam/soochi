Below is a partial code showing the usage of useState. It does 2 things.
1. Imports useState
2. Invokes useState and stores its return value for further use.

import React, {useState} from "react";
export default function App() {
  const [showText, setShowText] = useState("")
}

Now we know how to add a state to a React component (we are using useState hook). Try to recall why we came to useState. We came to useState because it will help us to change UI based on a user action. The way to achieve this is as follows.
1. Identify the UI element that needs to be updated (in our case this is a paragraph tag).
2. Make that element use the current state variable (recall that the useState returns current state and set function).
3. When you handle user action, call the set function to set the new state.
Once we implement these 3 steps, React will automatically update the UI.

Below is an example showing the implementation of the above 3 steps.

import React, { useState } from "react";
export default function App() {
  const [showText, setShowText] = useState("")
  function updateText(){
    // step 3
    setShowText("Hello, I've learnt to use the full-stack evaluation tool. This makes me so happy!!!");
  }
  return (
    <div>
      <button onClick = {updateText}>Click</button>
      <p>{showText}</p> {/* steps 1 and 2 */}
    </div>
  )
}

In the above code snippet, inside updateText function, we are calling setShowText in order to change the state of showText. Bablu suggested an alternative way. He gave the below snippet. Is this correct?

function updateText() {
  showText = "Hello, I've learnt to use the full-stack evaluation tool. This makes me so happy!!!";
}

Yes - This answer is incorrect.
No - This is correct answer.

You should never modify the state variable directly. It won't give you any error. But it also won't work correctly. You should always use the set function only.
