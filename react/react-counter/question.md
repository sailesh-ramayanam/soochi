# Description

Write logic for increment, decrement and reset button for given counter application in `React`.  
You would already know how to do it using `HTML/CSS/JS`.  
The code for buttons is already given in `React`. You just need to implement logic.

# Requirements

## UI requirements

1. Title of the buttons should be `Increment`, `Decrement` and `Reset` for `Increment`, `Decrement` and `Reset` button respectively.
2. Initially counter value should be `0`.

## Functional requirements

1. On clicking the `Increment` button counter value must increase by 1.
2. On clicking the `Decrement` button counter value must decrease by 1.
3. On clicking the `Reset` button counter value must reset to 0.
4. Minimum value for counter should be 0.
