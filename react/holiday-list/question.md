# Description

You'll be given a list of cities and their home countries, Your task is to filter out to only those cities, that are having their home country as India

example : 
```
const cityList :
{ name: 'Jaipur', country: 'India' },
{ name: 'The Hofburg', country: 'Austria' },
{ name: 'Belvedere Palace', country: 'Austria' },
{ name: 'St. Stephen Cathedral', country: 'Austria' },
{ name: 'Kahna National Park', country: 'India' },
{ name: 'Amritsar', country: 'India' },
{ name: 'Mussoorie', country: 'India' },
```

output
```
1. Jaipur
2. Kahna National Park
3. Amritsar
4. Mussoorie
```

# Requirements

## Other requirements

1. your output cities should be a list of `ol` elements
