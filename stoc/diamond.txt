Logic means step-by-step procedure which explains how to calculate the result for the given input.
This step-by-step procedure is also called as algorithm.

One way to come up with an algorithm is by using the test cases we wrote down previosuly.

Following is a hint.
On a paper, write the following in a tabular format

- number of lines in the pattern for n

There is a mathematical relation between n and the number of lines in the pattern for n. What is it?
2*n - 1 - This is correct answer.
2*n - This answer is incorrect. Please observe the above patterns carefully.
2*n + 1
n + 2

There is a difference in the first lines for different n's. What is the difference?
Number of *'s - This answer is incorrect. Please observe the above patterns carefully.
Position of *'s - This is correct answer. For any n, the first line contains a single *. But for n=1, it has no spaces before it, for n=2, there is 1 space before it and so on.
Both number and position - This answer is incorrect. Please observe the above patterns carefully.

There is also another fact. For each n, we start with one *. Then we will have 3 stars. Then 5 stars and so on, the stars keep increasing, until a point.

After that, the number of stars starts decreasing, until we print the final line, which will have a single *.

Till which line do the stars keep on increasing?
nth line - This is correct answer.
(n-1)th line - This answer is incorrect. Please observe the above patterns carefully.
(n+1)th line

Based on these, we can separate the pattern into 2 parts. Increasing part and decreasing part. How many lines do the increasing part and decreasing part contain respectively?
n-1, n-1 - This answer is incorrect. Please observe the above patterns carefully.
n, n
n, n-1 - This is correct answer.
n-1, n

Now, notice that in the increasing part, the number of stars are increasing but the number of spaces are decreasing.
On a paper, write the following in a tabular format.
- n
- number of spaces in first line

How many spaces are there in the first line?
n spaces - This answer is incorrect. Please observe the above patterns carefully.
n-1 spaces - This is correct answer. First line of the diamond pattern will contain (n-1) spaces and 1 star.
n+1 spaces - This answer is incorrect. Please observe the above patterns carefully.

In the increasing part of the pattern, from one line to the next line, the number of spaces decrease and the number of stars increase. From one line to the next line, how many spaces get decreased and how many stars get increased?
1 space, 1 star - This answer is incorrect. Please observe the above patterns carefully.
1 space, 2 stars - This is correct answer.
2 spaces, 2 stars - This answer is incorrect. Please observe the above patterns carefully.

Exact reverse happens in the decreasing part.

Let us try to summarize our observations.
1. The pattern has 2*n-1 lines
2. Any pattern will start with (n-1) spaces followed by 1 star
3. Each next line will have 1 less space and 2 more stars
4. This way we will have n lines
5. After that, each next line will have 1 more space and 2 less stars
6. This way we will have (n-1) lines

Based on this, try to write an algorithm to print the diamond pattern.

Following is what I came up with.
1. Read n
2. Initialize numSpaces as (n-1)
3. Initialize numStars as 1
4. Repeat the below steps (5.1 to 5.6) for n times
5.1. Initialize patLine to be an empty string
5.2. Run a loop for numSpaces iterations, in each iteration add 1 space to patLine
5.3. Run a loop for numStars iterations, in each iteration add 1 star to patLine
5.4. Print patLine
5.5. Decrement numSpaces by 1
5.6. Increment numStars by 2
6. Set numSpaces to 1
7. Set numStars to 2*n-3
8. Repeat the below steps (9.1 to 9.6) for (n-1) times
9.1. Initialize patLine to be an empty string
9.2. Run a loop for numSpaces iterations, in each iteration add 1 space to patLine
9.3. Run a loop for numStars iterations, in each iteration add 1 star to patLine
9.4. Print patLine
9.5. Increment numSpaces by 1
9.6. Decrement numStars by 2
