# Description

Suppose you have a container and you want to place the item in it with evenly spaced always. Also whenever we add more items new items get added in new row rather than squeezing the existing items.
You have to implement the above criteria using HTML/CSS.

# Requirements

## UI requirements

1. A container having a border.
2. Inside the container there may be multiple items.

Please refer to `Sample UI` section below, for an example.

## Other requirements

1. Keep all items inside a single div tag.
2. Div tag should have an attribute `id` with its value `holder`.
3. All the items must render inside separate div tag having attribute as `class` and its value `item`

## hints

- Use style `display: flex`.
