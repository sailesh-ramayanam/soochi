# Description

Create a start page that you will use as the default page in your browser. Include the following items in this start page:

1.  Add two full width block divisions, the first full-width division needs to be divided in two equal parts, the first division should have a list and the second division should have an image.

2.  Second full width block divisions need to be divided in two equal parts, first division should have an image and another division should contain heading.

# Requirements

## UI requirements

1. HTML page should have 4 blocks with 50% of width and 50% of height of entire page.
2. First block should display unordered list items.
3. Second block should display image containing whole width of the page.
4. Third block should also display image containing whole width of the page.
5. Fourth block should have text.

Please refer to `Sample UI` section below, for an example. You can use images of your preferred choice.

## Other requirements

1. Keep all the blocks inside 1 div with.
2. Main div should contain an attribute `class` and its value should be `div`.
3. Inside main div, there should be 2 more divs for upper half and lower lower respectively.
4. All blocks should have an attribute `class` with value as `block-1`, `block-2`, `block-3`, `block-4` for top left, top right, bottom left and bottom right blocks respectively.
5. Text in the fourth block must be rendered inside h1 tag.
