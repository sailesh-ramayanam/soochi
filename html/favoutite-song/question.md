# Description

What is your favourite song? Can you direct us to its youtube link, using `HTML/CSS`.
Create a static HTML page that displays `<Favourite song>`, after clicking song link it will redirect to its youtube link.

# Requirements

## UI requirements

1. A text for your favaourite song.
   - `My current favourite song is <song-name>.`
   - E.g. `My current favourite song is is Paradise.`

Please refer to `Sample UI` section below, for an example. You can use song name and youtube link of your preferred choice.

## Other requirements

1. Text must be rendered inside a h2 tag.
2. Link the text to the official youtube link of the song through anchor tags.
3. All the content should be inside div tag.

## Hints

1. Anchor element should contain an attribute `target` and its value should be `_blank`.
