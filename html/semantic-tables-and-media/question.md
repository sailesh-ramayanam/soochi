# Description

Create a table using HTML/CSS.

- The table will have two columns, one for "Roll numbers" and another for "Names".
- The table will contain only 3 rows of data i.e 6 cells in total. Data can be of your choice.

Below image there should be 3 items

- The first item will be a image
- The second item will be a video
- The third and last item will be an audio

# Requirements

## UI requirements

1. A table with only two columns.
2. Title of first column should be `Roll numbers` and title of second column should be `Names`.
3. There should be 3 cells in both columns.
4. Below table render a title `List of medias`
5. Three media i.e image, video and audio should render below the title.

Please refer to `Sample UI` section below, for an example.

## Other requirements

1. All the media should be inside ordered list.
2. Image media should render inside image tag.
3. Image tag should have an attribute `src` with its value `https://picsum.photos/id/123/200/300`.
4. Video should be rendered inside video tag.
5. Video tag should have an attribute `src` with its value `http://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`.
6. Audio should be rendered inside audio tag.
7. Audio tag should have an attribute `src` with its value `http://commondatastorage.googleapis.com/codeskulptor-assets/Epoq-Lepidoptera.ogg`.
8. `List of medias` text must be rendered inside h1 tag.

## hints

- Use `table` tag for creating table and `tr` tag for rows
