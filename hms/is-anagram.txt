These hints are almost like an algorithm, but one major point is not mentioned in these hints.
How do we store the counts of every character of the 1st string?
This is where our data structure skills come into picture.

There are multiple ways to solve this problem.
Variables approach: Use variables like a_count, b_count, c_count etc. to store the counts.
Arrays approach: Use 2 arrays. In one array store the character, and in the second array store the corresponding count.
Hashmap approach: Use a hashmap to store <character, count> key value pairs.

This method will look like below.
let a_count = 0, b_count = 0, and so on z_count = 0;
for each character c in word {
    if (c === "a") {
        a_count++;
    } else if (c === "b") {
        b_count++;
    } and so on until else if (c === "z") {
        z_count++;
    }
}

There are multiple issues with this approach.

You have to create 26 variables and write 26 if conditions. That is also not sufficient.
What about uppercase letters (i.e. A, B, C, ... Z)?
What about digits (i.e. 0, 1, 2, 3 ... 9)?
What about special characters (like @, #, $, %, ;, ', and so on)?
We will have to create 100s of variables and write 100s of if conditions. Even if we miss one character, our program will not work correctly.

This is a correct approach, but not a practical approach.

Below is an implementation of the hashmap approach.
1. let charMap = new Map();
2. for (let i = 0; i < word.length; ++i) {
3.     let c = word.charAt(i);
4.     if (charMap.has(c)) {
5.         charMap.set(c, charMap.get(c) + 1);
6.     } else {
7.         charMap.set(c, 1);
8.     }
9. }
